# Workspace Execution Rules

## Fast & Direct Execution
- **No Test Runs by Agent**: Do NOT run test suites (`pytest`, `vitest`, `npm test`, etc.) automatically. The user will run and verify all tests themselves.
- **Direct & Fast Action**: Execute requested changes, edits, git commands, and code updates directly without unnecessary file reads, exploration loops, or diagnostic delays.
- **Minimal Verbosity**: Keep responses concise, direct, and actionable.
